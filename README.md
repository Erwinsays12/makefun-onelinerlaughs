Entry for the [One-Liner Laughs](https://make.fun/c/u-coral-404-one-liner-laughs-aa872d41) competition on make.fun.

## What it does

`main.ts` writes a single funny line (128 characters) to `/output/entry.txt`:

> I tried meal prepping. Day one: five identical containers. Day three: I ate cereal over the sink like a raccoon with a mortgage.

The line was picked by an internal head-to-head tournament over a pool of 12 original one-liner candidates, judged on the competition's own rubric: a clear setup and payoff, laugh-out-loud funny, a surprising twist, a fresh angle, and tight wording.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. The program is deterministic: it writes the same line on every run, uses no network and no environment input, and refuses to write anything outside the gate's 1–200 character range.
